# Cute Bloody Stream

Браузерная арена-выживалка с автострельбой. Постапокалипсис: люди живут в бункерах и смотрят стримы с поверхности. Стримерша выходит на арену с зомби, проводит 20 стримов-волн, между ними покупает улучшения на донаты, а после 20-го стрима её забирает вертолёт. Чат зрителей реагирует на всё, что происходит в бою.

Игра на Phaser 3.90 + TypeScript + Vite, работает в браузере без сервера. Логический размер экрана 1920×1080, картинка масштабируется под окно.

## Как играть

### Забег

1. **Выбор стримерши.** Три героини с разным оружием и стартовыми характеристиками.
2. **Стрим (ночь).** Бой на арене. Цель стрима — набрать очки стиля до порога **STYLE GOAL**. Как только полоса заполнена, стрим заканчивается, все враги на арене погибают, начисляются монеты.
3. **День.** Магазин: монеты тратятся на улучшения характеристик. Затем следующий стрим.
4. После **20-го** стрима — финал: вертолёт спускает лестницу и забирает героиню. Героиня получает отметку «✓ Пройдено» на экране выбора.

Смерть обрывает забег: всё купленное и накопленное теряется, остаётся только отметка «Пройдено» у героинь, которые уже проходили игру. HP в начале каждого стрима восстанавливается до максимума.

### Стрим

- **Карточка доната.** В начале стрима зритель присылает донат с заданием, например «Убей 15 зомби». За выполнение — монеты сразу. На первом стриме забега под карточкой показывается сводка управления с выбором режима стрельбы.
- **Стиль.** Каждое убийство даёт очки стиля: базовые очки врага + бонусы (крит, дальний выстрел, убийство вплотную), всё это × множитель серии. Серия (combo) растёт с каждым убийством и сбрасывается, если героиня получила урон или не убивала `comboWindow` секунд.
- **HYPE.** Ранг D → C → B → A → S → SS по длине серии. Только визуал и реакции чата.
- **Появление врагов.** Врагов заранее отмечает красный крестик, они появляются группами, не ближе `minDistance` к героине.
- **Урон.** Враги бьют касанием. После удара героиня на `invulnerability` секунд неуязвима (мигает).
- **Монеты.** Падают с убитых врагов с шансом «Поиска ресурсов» и притягиваются к героине.
- **Итоги стрима.** Монеты с дропа + награда за задание + floor(стиль × `styleToCoins`).

### Стримы с боссом

На стримах 10 и 20 на арене появляется **Хейтер**. Он преследует героиню, раз в несколько секунд показывает красную линию и делает рывок по ней, периодически призывает шатунов. Стрим с боссом заканчивается, только когда **и** порог стиля набран, **и** босс убит. После порога обычные враги перестают появляться и больше ничего не дают. Когда босс вне экрана, на краю видна стрелка к нему.

### Магазин и характеристики

Девять характеристик. Каждая покупка добавляет очки характеристики, цена растёт с каждой покупкой той же характеристики. Итоговое значение многих характеристик = база × F(очки), где F(s) = clamp(1 + s/100, 0,1, 5).

| Характеристика | Что даёт | Формула |
|---|---|---|
| Здоровье | Максимум HP | `baseHp` × F(hp) |
| Урон | Урон снаряда | урон оружия × F(damage) |
| Скорость атаки | Выстрелов в секунду | `fireRate` × F(attackSpeed) |
| Скорость передвижения | px/с | `baseMoveSpeed` × F(moveSpeed) |
| Дальность атаки | Радиус автоприцела и дальность полёта снаряда | `range` × F(range) |
| Броня | Снижение получаемого урона | урон × (1 − A / (A + 15)) |
| Восстановление | HP в секунду | очки / 5 |
| Шанс крита | % | шанс оружия + очки |
| Поиск ресурсов | Шанс выпадения монеты с врага, % | очки |

### Чат

Справа вверху — чат стрима. Около 100 зрителей с постоянными номерами бункеров, 12 завсегдатаев со своей манерой (любитель тушёнки, модератор, паникёр, фанат яндере, тролль хейтера…). Чат комментирует убийства, криты, удары по героине, серии, задание, босса, низкое HP, смерть и финал, отвечает друг другу короткими диалогами, модератор банит тролля. Реплики зависят от героини, врага, этапа забега и ситуации. Число зрителей LIVE растёт со стилем, набранным за забег.

### Арена

Арена 2880×1620 больше экрана, камера следует за героиней. По краю — забор с колючей проволокой; за забором видна затемнённая полоса с обломками: сгоревшая машина и генератор с огнём, ящики, вентиляция. На полу — подпалины и мусор, во время боя остаются пятна крови.

### Звук и музыка

Звуки выстрелов и перезарядки для каждого оружия. Музыка: в главном меню — свой трек по кругу; при старте забега он затихает, а через секунду после начала первого стрима начинается плейлист забега (4 трека по кругу с паузой между ними). В магазине музыка тише, но не прерывается. После смерти или финала экран выбора возвращает трек меню.

Значок ⚙ в правом верхнем углу любого экрана открывает настройки громкости: «Звук выстрелов» и «Музыка». По умолчанию выстрелы на 3 %, музыка на 5 %. Во время боя окно ставит стрим на паузу.

## Управление

| Клавиша | Действие |
|---|---|
| WASD / стрелки | Движение |
| `Q` | Режим стрельбы: **автоприцел** (стреляет сама по ближайшему врагу в радиусе) ↔ **ручной** (прицел — мышью, огонь — пока зажата ЛКМ). Выбор запоминается |
| ЛКМ | Огонь в ручном режиме |
| `F` | Оттолкнуть врагов вокруг. Освобождает от трости сталкера. Перезарядка 1,3 с |
| Пробел | Рывок в сторону движения (без нажатых стрелок — куда смотрит героиня): неуязвимость, враги на пути разлетаются в стороны, освобождает от трости. Перезарядка 14 с |
| `Esc` | В бою — пауза (продолжить или выйти в меню); на итогах стрима и в магазине — выйти в меню с потерей забега; на экране выбранной героини — назад |
| Любая клавиша / клик | Закрыть карточку доната и начать бой (кроме `Q`: он переключает режим) |
| Пробел / Enter | На итогах стрима — «Дальше» |
| Колесо мыши | Прокрутка чата |

Перезарядка F и пробела и текущий режим стрельбы видны внизу слева, рядом с HP и монетами.

## Запуск, сборка, выкладка

Нужен Node.js 22 (подойдёт 18+).

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # проверка типов + сборка в dist/
npm run preview    # просмотр сборки, http://localhost:4173
```

Сборка — статические файлы в `dist/`. Все пути относительные (`base: './'`), поэтому игра работает из любой подпапки сайта.

**GitHub Pages.** Workflow `.github/workflows/pages.yml` собирает игру и выкладывает `dist/` при каждом пуше в `main`. Один раз в репозитории: **Settings → Pages → Build and deployment → Source: GitHub Actions**. Адрес игры: `https://<user>.github.io/<repo>/`.

**Правка параметров без пересборки.** Конфиги `balance.json`, `chat.json`, `assets.json` загружаются при запуске страницы. Их можно менять прямо в собранной игре (`dist/config/`): изменения применяются после перезагрузки страницы.

## Отладочный режим

Параметры адресной строки, например `?debug=1&heroine=kuudere&stream=20&god=1&coins=500`:

| Параметр | Действие |
|---|---|
| `debug=1` | Внизу экрана FPS, число врагов, время стрима; `F9` — сразу завершить текущий стрим (и убить босса); в консоли объект `window.cbs` (`game`, `ctx`) |
| `heroine=<id>` | Сразу начать забег героиней `genki`, `kuudere` или `yandere`, минуя экран выбора |
| `stream=<n>` | Начать со стрима n (1–20) |
| `god=1` | Героиня не получает урон |
| `coins=<n>` | Стартовые монеты |
| `speed=<n>` | Ускорение боя в n раз (1–8) |

## Устройство проекта

```
index.html                      страница, стили DOM-элементов (чат, карточка доната, сводка управления, настройки)
public/config/balance.json      все числа игры
public/config/chat.json         зрители и реплики чата
public/config/assets.json       картинки, спрайты, звуки, музыка, окружение арены
public/assets/img/<id>/         портреты героинь и фоны-бункеры
public/assets/sprites/          спрайт-листы героинь, врагов, босса; оружие
public/assets/env/              пол, забор, объекты окружения, огонь, трость сталкера, вертолёт, лестница
public/assets/sounds/           звуки оружия
public/assets/music/            музыка
src/main.ts                     создание игры Phaser
src/scenes/                     Boot (загрузка), Select, Night (стрим), Day (магазин), Result, Final
src/entities/                   Player, Enemy (включая охотника и сталкера), Boss, Projectile, Coin
src/systems/                    состояние забега, характеристики, стиль, задания, магазин, спавн, чат,
                                арена, кровь, звук, музыка, настройки, сохранение, загрузка ассетов, отладка
src/ui/                         HUD, панель чата, окно настроек, виджеты, цифры урона
```

Устройство кода:
- Все числа баланса — в `balance.json`, все пути к ассетам — в `assets.json`, код их не дублирует. Число стримов (20) — константа `STREAMS` в `Night.ts`.
- Нет файла или записи в `assets.json` — предупреждение в консоли и цветной плейсхолдер, игра не падает. Хитбоксы задаются в `balance.json` и не зависят от картинок.
- Враги, снаряды и монеты берутся из пулов объектов. На позднем стриме с 70+ врагами держится 55–60 FPS.
- Чат, карточка доната, сводка управления и окно настроек — HTML поверх canvas, масштабируются вместе с игрой.

## Параметры: `balance.json`

В таблицах: **значение** — текущее значение в конфиге; n — номер стрима (1…20); F(s) = clamp(1 + s/100, `minFactor`, `maxFactor`) — множитель характеристики по её очкам.

### `world` — арена и камера

| Параметр | Значение | Смысл |
|---|---|---|
| `arena.width`, `arena.height` | 2880, 1620 | Размер арены, px. Героиня, враги и точки появления ограничены им |
| `camera.lerp` | 0.1 | Плавность следования камеры (0…1, больше — жёстче) |
| `separation` | 0.5 | Насколько враги расталкивают друг друга за кадр (0 — проходят сквозь, 1 — жёстко) |

### `stats` — формулы характеристик

| Параметр | Значение | Смысл |
|---|---|---|
| `minFactor`, `maxFactor` | 0.1, 5 | Границы множителя F(s) |
| `armorK` | 15 | Броня: получаемый урон × (1 − A / (A + armorK)), A — очки брони |
| `regenAlpha` | 5 | Восстановление: HP в секунду = очки regen / regenAlpha |

### `player` — героиня

| Параметр | Значение | Смысл |
|---|---|---|
| `invulnerability` | 0.5 | Секунды неуязвимости после удара |

| `lowHpRatio` | 0.3 | Доля HP, ниже которой чат тревожится (`low_hp`) |

### `abilities` — F и пробел

| Параметр | Значение | Смысл |
|---|---|---|
| `push.cooldown` | 1.3 | Перезарядка толчка (F), с |

## Параметры: `chat.json`

Зрители и реплики. Код определяет формат по полям; старый формат (только `nicks` и строки в `messages`) тоже работает.

### Верхний уровень

| Поле | Текущее | Смысл |
|---|---|---|
| `nicks` | 90 ников | Обычные зрители |

### Слои

У категории есть базовый слой (`kill`) и специальные с суффиксом: героиня (`kill_genki`), враг (`kill_walker`, `player_hit_boss_hater`) для `kill` и `player_hit`, тип задания (`task_new_noHit`) для `task_*`. Доли слоёв задаёт `layers`: `layers[категория][тип] ?? layers.default[тип]`, базе — остаток до 1. Сейчас `default`: героиня 0.4, враг 0.5, задание 0.5; для `kill`: враг 0.55, героиня 0.15; для `idle`: героиня 0.3. Без поля `layers` слой героини просто заменяет общую категорию.

### Условия `if`

Ключи объединяются через И, массив — «любое из». Нет данных для условия — ложно. Неизвестный ключ — предупреждение в консоли, запись недоступна.

| Ключ | Истинно, когда |
|---|---|
| `heroine` | выбрана эта героиня |
| `stage` | стрим в этапе из `stages` |
| `stream` | номер стрима N или в диапазоне [мин, макс] |
| `boss`, `bossAlive` | стрим с боссом; босс на арене и жив |
| `enemy`, `variant` | враг события; вариант внешности (шатун: 1 — офисный, 2 — худи) |
| `rank`, `rankMin`, `comboMin` | ранг HYPE; не ниже ранга; серия ≥ N |
| `hpBelow`, `hpAbove` | доля HP ниже / выше |
| `viewersMin`, `viewersMax`, `killsMin` | зрителей ≥ / ≤ N; убийств за стрим ≥ N |
| `task`, `taskDone`, `taskNear` | тип задания; выполнено; почти выполнено |
| `cleared` | героиня уже проходила игру |

### Переменные

| Переменная | Значение |
|---|---|
| `{author}`, `{nick}` | Автор реплики; упомянутый зритель (в ответе — автор родителя) |
| `{bunker}`, `{nickBunker}`, `{randomBunker}` | Бункер автора, упомянутого, случайный |
| `{streamer}` | Имя героини |
| `{stream}`, `{streamsLeft}`, `{n}` | Номер стрима, сколько осталось; `{n}` — стрим в `stream_*`, серия в `combo` |
| `{viewers}`, `{combo}`, `{rank}`, `{kills}` | Зрители, серия (в `combo_lost` — потерянная), ранг, убийства за стрим |
| `{donor}`, `{task}`, `{target}`, `{left}`, `{amount}` | Донатер, текст задания, цель, сколько осталось, награда со словом («24 монеты») |
| `{enemy}` | Название врага |

Неизвестная переменная остаётся в тексте как есть и один раз пишет предупреждение в консоль.

### Как выбирается реплика

1. Собираются слои категории, из каждого — записи, у которых выполнено `if`, есть автор для `by`, не исчерпан `once` и шаблона нет среди последних `recentTextMemory`.
2. Слой выбирается по долям `layers`, запись — по `weight`.
3. Если подходящих нет, повтор разрешается: берётся запись, которая звучала давнее всех.
4. Автор: `by` → завсегдатай или донатер; иначе с долей `regularShare` — завсегдатай; иначе случайный ник, не писавший недавно.

## Параметры: `assets.json`

Все пути — относительно `public/`. Пустое значение (`null`) или незагрузившийся файл — предупреждение в консоли и плейсхолдер.

### `portraits.<id>`

`base` — карточка на экране выбора, `selected` — героиня в полный рост, `background` — фон-бункер за ней (масштаб «cover»).

### `sprites.<key>`

Ключи: `hero_<id>`, `enemy_<id>`, `boss_hater`, `weapon_<weaponId>`. Листы героинь и врагов — 3 кадра 256×256 (спереди, сзади, справа; «влево» — отражение), у босса — 384×384, у сталкера четвёртый кадр — поза броска трости. Шаг при ходьбе рисуется кодом (покачивание и сжатие).

| Поле | Смысл | Текущее |
|---|---|---|
| `sheet` | Спрайт-лист (кадры слева направо, сверху вниз) | |
| `image` | Одиночная картинка (оружие) | |
| `frameWidth`, `frameHeight` | Размер кадра | 256 (босс 384) |
| `scale` | Масштаб отрисовки | героини 0.45; шатун 0.42, бегун 0.36, громила 0.62, охотник 0.4, сталкер 0.46, босс 0.95; оружие 0.5 |
| `origin` | Точка привязки [x, y] в долях кадра | [0.5, 0.78] — ноги |
| `weaponAnchor` | Смещение точки крепления оружия от героини, px | [0, −10] |
| `anims.<name>` | `frames` — номера кадров, `fps` | |
| `mirror` | Какие анимации получаются отражением других: `"move_left": "move_right"` | |
| `placeholder` | `{ shape: rect \| circle, w, h, color }`; без него — `size` и `color` из `balance.json` | |
| `variants` | Вместо всего остального: список ключей, из которых выбирается случайный (два вида шатуна) | `enemy_walker` |
| `bob` | Покачивание при ходьбе `{ amp, freq, squash }` | по умолчанию `{ 5, 14, 0.06 }` |

У оружия `origin` — точка хвата; снаряды вылетают из конца ствола.

Имена анимаций: героини — `idle_<dir>`, `move_<dir>` (`down`, `up`, `right`, `left`); враги — `move_<dir>` для 8 направлений, `attack_right|left`, `death`, у сталкера `cast_right|left`; босс — плюс `telegraph_right|left`, `dash_right|left`, `summon`. Цепочка отката: анимация → зеркальная пара → `idle_<dir>` → `idle_down` → кадр 0 → плейсхолдер.

### `images`

| Ключ | Что | Текущее |
|---|---|---|
| `arena_bg` | Тайл пола арены (и финала) | `assets/env/floor.jpg` |
| `helicopter` | Вертолёт в финале | `assets/env/helicopter.png` |
| `ladder` | Верёвочная лестница в финале, разматывается сверху вниз | `assets/env/ladder.png` |
| `select_bg`, `coin`, `spawn_marker`, `boss_arrow`, `projectile_rifle`, `projectile_laser`, `projectile_shotgun` | Фон выбора, монета, крестик появления, стрелка к боссу, снаряды | `null` — рисуются кодом |

### `soundVolume`, `sounds`

Звук — файл или цепочка других звуков. Нет записи или файла — тишина.

| Поле | Смысл |
|---|---|
| `soundVolume` | Общая громкость звуков: **0.8** |
| `path` | Файл |
| `volume` | Громкость 0…1 |
| `detune` | Случайный сдвиг высоты ± центов (100 = полутон) |
| `max` | Сколько копий звучит одновременно |
| `sequence` | Цепочка: каждая часть начинается после окончания предыдущей |
| `interrupt` | `true` (по умолчанию) — новый запуск обрывает хвост предыдущей цепочки |
| `tailToPeriod` | Выстрел: хвост обрезается до интервала между выстрелами, ритм очереди слышен при любой скорости атаки |
| `rateScale`, `maxRate` | Выстрел: ускорение воспроизведения 1 + rateScale × (скорострельность / базовая − 1), не больше maxRate (по умолчанию 1.5) |

| Событие | Текущее |
|---|---|
| `fire_rifle` | `rifle_shot.mp3`, volume 0.45, detune 80, max 5, tailToPeriod, rateScale 0.3, maxRate 1.4 |
| `fire_laser` | `laser_shot.mp3`, volume 0.7, detune 40, max 3 |
| `fire_shotgun` | `shotgun_shot.mp3`, volume 0.8, detune 60 |
| `reload_rifle` | цепочка `rifle_reload_1` → `rifle_reload_2`, volume 0.6 |
| `reload_shotgun` | цепочка `shotgun_pump_1` → `shotgun_pump_2`, volume 0.6 |

Итоговая громкость = `soundVolume` × `volume` × ползунок «Звук выстрелов».

### `music`

| Поле | Значение | Смысл |
|---|---|---|
| `volume` | 0.5 | Громкость музыки; итог = volume × ползунок «Музыка» |
| `menu` | `assets/music/menu.mp3` | Трек главного меню, по кругу. При старте забега плавно затихает |
| `run` | survivor → glitch → survivor → glitch-2 | Плейлист забега по кругу. Играет без перерыва через все стримы и магазин |
| `startDelay` | 1 | Через сколько секунд после начала 1-го стрима стартует плейлист |
| `gap` | 2.5 | Пауза между треками забега, с |
| `fade` | 1.5 | Время затухания и нарастания при смене трека меню / забега, с |
| `shopVolume` | 0.3 | Громкость в магазине — доля от обычной |

Треки выровнены по громкости (−16 LUFS), в конце каждого — затухание 3 с, поэтому петля и смена трека не щёлкают.

### `cane`

Трость сталкера: `shaft` — тайл стержня (тянется от руки до конца), `open` и `closed` — конец трости в полёте и в хвате. Файлы `assets/env/cane-*.png`.

### `arena`

| Поле | Значение | Смысл |
|---|---|---|
| `border` | 220 | Полоса за забором, которую видно у края арены, px. В неё никто не заходит — там стоят объекты |
| `fence.h`, `fence.v` | `fence-h.png`, `fence-v.png` | Тайлы забора: горизонтальный (верх и низ) и вертикальный (бока). Нет поля или картинок — вместо забора розовая линия |
| `fence.scale` | 1 | Масштаб забора |
| `fence.bottomAlpha` | 0.45 | Прозрачность нижнего забора, когда героиня стоит за ним |
| `floorBrightness` | 0.5 | Яркость пола 0…1 (и в финале) |
| `floorScale` | 1 | Масштаб тайла пола |
| `dim` | 0.55 | Яркость всего за забором: пол полосы, объекты, декали |
| `props[]` | 23 объекта | Объекты окружения, см. ниже |

Поля объекта в `props`:

| Поле | Смысл |
|---|---|
| `img` / `frames` | Картинка / кадры огня (огонь мерцает и светится) |
| `x`, `y` | Координаты арены (0…2880, 0…1620; за забором — меньше 0 или больше размера). У объектов и огня — середина нижнего края, у декалей — центр |
| `flat` | Декаль на полу (подпалина, мусор) — под всеми, тонируется как пол |
| `scale`, `angle`, `flip`, `alpha` | Масштаб, поворот в градусах, отражение, прозрачность |
| `depthOf` | Огонь: индекс объекта в `props`, на котором он горит (без поля — ближайший) |

Объёмные объекты сортируются по нижнему краю. Если объект заходит за забор на поле или картинка не загрузилась — предупреждение `[arena]` в консоли.
